# 計算機プログラム
初めてのプログラミング「Python」です。

## 説明
シンプルな計算機プログラムです。2つの数字と演算子を入力すると、計算結果を表示します。

## 機能
- 足し算（+）
- 引き算（-）
- 掛け算（*）
- 割り算（/）
- ゼロ割りエラーチェック

## 使い方

### Google Colab での実行
1. Google Colab にアクセス
2. コードをコピーして貼り付け
3. 実行ボタンをクリック

### ローカルパソコンでの実行
python calculator.py

## 実行例
=== シンプル計算機 ===

最初の数字を入力してください: 10
演算子を入力してください (+, -, *, /): +
2番目の数字を入力してください: 5

10.0 + 5.0 = 15.0
